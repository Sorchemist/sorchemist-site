# Sorchemist — Sihirli Kimya Akademisi

www.sorchemist.com için statik web sitesi.

- `index.html` – ana sayfa (giriş ekranı, 3D vadi sahnesi, periyodik cetvel)
- `konular.html` – Lise 1-2-3-4 kimya üniteleri (29 ünite)
- `deneyler.html` – demirci örsü ve iksir masası simülasyonları
- `assets/` – ortak CSS, JS ve WebGL sahnesi
- `data/` – ünite, deney ve element verileri

Derleme gerektirmez; dosyalar doğrudan sunucunun kök dizinine (public_html) yüklenir.
